SOURCE CAVEAT — READ BEFORE RENDERING AS FACT

Fault-to-well proximity is inconsistent within the source itself. The paper's Discussion section places the proven thrust fault (Fault B) "near LHD 12"; its Conclusion instead places Fault B "near LHD 8." This diagram follows the Discussion-section version.

The general and local framings disagree. At field scale, the paper states NW-SE thrust faults generally admit fluid flow to production wells, while the NE-SW fault (Fault A) is the general barrier. It is only in the local LHD 8/11/12/18 compartmentalization discussion that both faults are jointly treated as barriers — which is what this diagram shows.

Implementation constraints

NO DYNAMIC SLICING
Silangkitang and Kamojang cross-sections carry no XYZ spatial grid. Both panels above are pre-digitized static SVGs with hover-driven data — not a slicing engine. Inequalities are ordinal, not magnitude: hover panels must not imply specific numeric values unless sourced separately (e.g. Simatupang 2020, Fig. 8's enthalpy–chloride cross-plot).
SALAK ONLY
If arbitrary line slicing ships in Phase 2, ground it strictly in Salak's UTM grid (Golla 2018) and 200 m × 200 m block model geometry (Kurniawan 2026). Confirm the grid carries actual property fields — temperature, chemistry, permeability at nodes — not just mesh geometry, before committing to this as a deliverable.

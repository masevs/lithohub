# Original feature prototypes (reference only)

These are the original standalone prototypes. They are **not** part of the app build anymore.
Their data has been moved to `public/data/fields.json` (F1, F2, F4, F3 field facts) and
`public/data/assets.json` (F3 well-pad series), and the features were rebuilt in `src/views/`.

Keep them for audit: if a value in the app looks wrong, compare it with the prototype here.
